# DUS Leads

Российская команда веб-разработки ищет компании, которым можно предложить сайт стоимостью около 15 000 рублей. Приложение сокращает ручной поиск и распределяет работу между сотрудниками.

Основной сценарий: выбрать города и категории, получить разрешённые данные из API или импортировать свой файл, оценить организации, назначить ответственного и вести историю контактов до оплаты и завершения заказа.

Пользователи: администратор команды и сотрудники. Общая база с авторизацией, история изменений и защита от одновременного назначения.

Данные: официальные API Яндекса и 2ГИС, CSV и XLSX. Отсутствующие значения остаются неизвестными. Неуказанный сайт не означает отсутствия сайта. Реальные организации не подменяются примерами; демонстрационные данные доступны только в отдельном режиме.

Интерфейс полностью русский. Девять разделов: дашборд, новый поиск, база клиентов, перспективные клиенты, CRM, сотрудники, аналитика, история поисков, настройки. Светлая и тёмная темы, графитовый фон и фиолетовый акцент заданы пользователем.

## Stack

React, TypeScript, Vite, Tailwind CSS, Lucide, Recharts. FastAPI, SQLAlchemy, Pydantic, HTTPX. PostgreSQL, Redis и Celery в Docker Compose. SQLite и встроенный исполнитель для локальной разработки без Docker.

## Ограничения

Сохранение и экспорт данных поставщиков требуют соответствующих договорных прав. Ключи хранятся в окружении сервера. Автоматических рассылок и обзвона нет. Проверка сайта использует ограниченный HTTP-анализ и не выдаёт его за браузерный аудит.
