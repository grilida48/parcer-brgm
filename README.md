# DUS Leads

Рабочее приложение для поиска организаций, оценки перспективности и ведения общей CRM команды веб-разработки. Интерфейс на русском языке.

## Возможности

- Поиск по нескольким городам и категориям через официальные API Яндекса и 2ГИС, ограничения рейтинга, отзывов, телефона, сайта и сетевого статуса.
- Импорт CSV/XLSX, дедупликация, фильтрация, сортировка, пагинация и массовое назначение клиентов.
- HTTP-анализ сайтов с защитой от запросов к внутренним сетям. Неуказанный сайт, непроверенный сайт, временная ошибка и подтверждённая недоступность различаются.
- Настраиваемая оценка 0–100 с объяснением каждого начисления. Это эвристика приоритета, а не вероятность продажи.
- CRM с 14 статусами, заметками, историей взаимодействий, следующим контактом, суммой заказа и учётом согласия.
- Администратор и сотрудники, общая база, версии записей для защиты от конфликтов назначения, журнал действий.
- Дашборд и аналитика по городам, категориям, сотрудникам; экспорт CSV, XLSX и JSON с проверкой прав источников.
- Светлая и тёмная темы, адаптивная навигация, отдельный демонстрационный режим.

Обычная база при первом запуске пустая. Приложение не генерирует организации для изображения результатов поиска. Синтетические записи создаются только отдельной командой в демонстрационном режиме.

## Быстрый запуск через Docker Compose

Нужны Docker Engine с Compose или Docker Desktop. На Windows используйте Linux containers.

```sh
cp .env.example .env
```

В PowerShell:

```powershell
Copy-Item .env.example .env
```

В `.env` замените `POSTGRES_PASSWORD` на случайный пароль из букв и цифр длиной от 24 символов. Для доступного из интернета сервера заранее задайте `ADMIN_EMAIL` и `ADMIN_PASSWORD` длиной от 12 символов. Для локальной установки можно оставить их пустыми и создать администратора в браузере.

```sh
docker compose up --build -d
```

Откройте [http://localhost:8000](http://localhost:8000). PostgreSQL и Redis доступны только внутри Compose; HTTP-порт приложения привязан к localhost. Для доступа команды используйте HTTPS reverse proxy. При HTTPS задайте `COOKIE_SECURE=true`.

```sh
docker compose logs -f app worker
docker compose down
```

Данные сохраняются в томах `postgres_data` и `redis_data`. `docker compose down -v` удаляет эти данные, поэтому не используйте эту команду для обычного перезапуска.

## Локальный запуск без Docker

Нужны Python 3.12 или новее и Node.js 22 с npm. Используется SQLite, задачи выполняются в процессе backend. Для совместной эксплуатации используйте PostgreSQL и Celery через Compose.

Windows PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start.ps1
```

Linux и macOS:

```sh
sh scripts/start.sh
```

Скрипты создают `.env` и виртуальное окружение, устанавливают зависимости, собирают интерфейс, применяют миграции и запускают приложение на [http://localhost:8000](http://localhost:8000).

Для разработки запустите два терминала.

Backend на Windows:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
cd backend
..\.venv\Scripts\python.exe -m alembic upgrade head
..\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

Backend на Linux/macOS:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
cd backend
../.venv/bin/python -m alembic upgrade head
../.venv/bin/python -m uvicorn app.main:app --reload
```

Frontend во втором терминале:

```sh
cd frontend
npm ci
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173). Vite проксирует `/api` на порт 8000.

## Подключение карт

Инструкции получения ключей, доступные поля и ограничения приведены в [docs/sources.md](docs/sources.md). Ключи находятся только в серверном `.env`. После изменения окружения перезапустите app и worker.

Без ключей работают импорт, база клиентов, CRM, проверка сайтов, аналитика и экспорт собственных данных. Интерфейс покажет, почему источник недоступен. Для 2ГИС дополнительно нужны права Regions API для точного выбора города и отдельные права на контакты.

`*_ALLOW_STORAGE` и `*_ALLOW_EXPORT` по умолчанию выключены. Включайте их только в соответствии со своим договором. Результаты не содержат придуманных рейтингов, телефонов или выводов об отсутствии сайта.

В настройках ограничивается количество запросов одного поиска; повторные попытки и запросы определения региона также учитываются. Стоимость запроса и лимит расходов задаются как оценка по вашему тарифу. Счёт поставщика остаётся источником фактической стоимости. Дополнительного HTTP-кеша нет.

## Импорт и экспорт

Используйте CSV UTF-8 с запятой, точкой с запятой или табуляцией, либо первый лист XLSX. Максимум 10 МБ и 10 000 строк; распакованный XLSX не должен превышать 50 МБ.

Обязательна колонка `name` или `Название`. Поддерживаются `category`, `city`, `address`, `phone`, `website`, `rating`, `review_count`, `email`, `card_url`; русские названия перечислены в [шаблоне CSV](docs/import-example.csv). Телефоны в Excel сохраняйте как текст, чтобы не потерять `+` и ведущие цифры.

Ошибки строк и число дубликатов показываются после загрузки. Выгрузка доступна для всей базы, выбранных организаций и конкретного поиска. Если хотя бы у одной записи отсутствует право экспорта, сервер отклонит выгрузку и предложит выбрать разрешённые записи. Формулы в строковых ячейках CSV/XLSX экранируются.

## Учётные записи и демонстрация

Администратор добавляет сотрудников в разделе «Сотрудники». CLI позволяет создать администратора без браузера. Выполняйте команды из `backend` с активным виртуальным окружением:

```sh
python -m app.cli create-admin --email admin@example.ru
```

Пароль запрашивается скрыто. Не передавайте его через командную строку.

Демонстрационные данные создавайте в отдельной базе. PowerShell:

```powershell
$env:DEMO_MODE='true'
$env:DATABASE_URL='sqlite:///./demo.db'
python -m app.cli demo
python -m uvicorn app.main:app --port 8001
```

Linux/macOS:

```sh
DEMO_MODE=true DATABASE_URL=sqlite:///./demo.db python -m app.cli demo
DEMO_MODE=true DATABASE_URL=sqlite:///./demo.db python -m uvicorn app.main:app --port 8001
```

Демо-организации явно подписаны и не имеют рабочих контактов. Приложение не выполняет обзвон или рассылку. Отказ от коммуникации снимает следующий контакт и блокирует регистрацию повторного рекламного звонка до фиксации нового согласия.

## Проверки

Из `backend`:

```sh
python -m pytest -q
```

Тесты создают отдельную временную базу. Проверяются авторизация, роли, CRM, конфликты версий, согласие, импорт, экспорт, оценка, ограничения источников, лимиты API и SSRF. HTTP-ответы источников в тестах подменяются; платные ключи не требуются.

Из `frontend`:

```sh
npm ci
npm run build
```

В GitHub Actions эти проверки запускаются через `.github/workflows/check.yml`. Описание выполненных проверок и ограничений текущего окружения находится в [docs/verification.md](docs/verification.md).

## GitHub Pages

Готов workflow публикации интерфейса на github.io. Backend и PostgreSQL размещаются отдельно: [инструкция](docs/github-pages.md). Адрес backend задаётся публичной переменной `VITE_API_BASE_URL`; ключи карт в frontend не передаются.

## Структура

```text
backend/app/          API, модели, CRM, оценка, адаптеры, проверка сайтов, задачи
backend/alembic/      миграции базы данных
backend/tests/        автоматические тесты
frontend/src/         React-интерфейс
docs/                источники, публикация, проверки
scripts/             локальный запуск Windows/Linux/macOS
compose.yaml         PostgreSQL, Redis, app и worker
```

При изменении схемы создавайте миграцию Alembic и выполняйте `alembic upgrade head`. Перед обновлением PostgreSQL делайте резервную копию через `pg_dump`; храните её вне репозитория и проверяйте восстановление в отдельной базе.

Локальный исполнитель не продолжает задачи после перезапуска процесса: частичные результаты сохраняются, задача отмечается прерванной. Для длительных поисков используйте Celery. HTTP-анализ не заменяет браузерное тестирование мобильной версии; его выводы и ограничения доступны в карточке организации.
