# Источники и права использования

Документация проверена 19 ноября 2026 года. Условия конкретного договора и состав прав ключа необходимо сверить перед подключением.

## Яндекс Карты

Используется официальный API Поиска по организациям: `https://search-maps.yandex.ru/v1/`, параметры `text`, `type=biz`, `lang=ru_RU`, `results`, `skip`, `apikey`.

Ключ создаётся в [кабинете разработчика](https://developer.tech.yandex.ru/). Выберите API Поиска по организациям, согласуйте коммерческий сценарий и право сохранять сведения в CRM. Запишите ключ в `YANDEX_API_KEY`. При наличии договорного разрешения задайте `YANDEX_ALLOW_STORAGE=true`; экспорт включается отдельно через `YANDEX_ALLOW_EXPORT`.

Адаптер использует документированные поля CompanyMetaData: название, адрес, категории, URL, телефоны и идентификатор. Рейтинг, число отзывов и признак сети не гарантированы документированным ответом, поэтому остаются неизвестными. Поиск возвращает релевантные организации, а не полный реестр всех компаний города.

Источники: [введение](https://yandex.ru/maps-api/docs/geosearch-api/index.html), [формат запроса](https://yandex.ru/maps-api/docs/geosearch-api/request.html), [формат ответа](https://yandex.ru/maps-api/docs/geosearch-api/response.html), [условия использования](https://yandex.ru/legal/maps_api/).

## 2ГИС

Используется Places API: `https://catalog.api.2gis.com/3.0/items`. Оформите ключ в [Platform Manager](https://platform.2gis.ru/), подключите Places API и согласуйте хранение данных в CRM и экспорт. Запишите ключ в `DGIS_API_KEY`, затем разрешённые договором флаги `DGIS_ALLOW_STORAGE` и `DGIS_ALLOW_EXPORT`.

Для ограничения поиска выбранным городом используется Regions API с фильтром России, затем `region_id` в Places API. Нужны права Regions API на том же ключе или отдельный `DGIS_REGIONS_API_KEY`. Неоднозначное название города требует уточнения. Результаты без подтверждённого города не сохраняются как результаты выбранного города.

Поле `items.contact_groups` требует дополнительных прав ключа и может оплачиваться отдельно. `DGIS_CONTACTS_ENABLED=true` следует устанавливать после подключения этих прав. Отсутствующий телефон, сайт или email не восстанавливается предположениями. Сведения о рейтинге и отзывах зависят от доступных полей; признак сети используется только при наличии данных бренда/организации.

Источники: [обзор Places API и получение ключа](https://docs.2gis.com/en/api/search/places/overview), [справочник поиска](https://docs.2gis.com/en/api/search/places/reference/3.0/items), [дополнительные поля](https://docs.2gis.com/en/api/search/places/examples/additional).

## Хранение и экспорт

Флаги окружения фиксируют подтверждённые владельцем права; они не предоставляют лицензию. По умолчанию получение данных в постоянную CRM заблокировано. Права экспорта сохраняются в каждой записи и учитываются сервером при выгрузке. Не включайте флаги ради обхода ограничений договора. Для договора с ограниченным сроком хранения необходимо организовать удаление данных в установленный срок; приложение не предполагает неограниченное право хранения.

CSV/XLSX подходят для собственных данных или сведений, на использование которых у команды есть права. Импорт не является способом обойти условия картографического сервиса. Не включайте непубличные персональные данные.

Внешний кеш ответов API отсутствует: повторные запросы учитываются в лимите поиска. Пагинация и повторные попытки также расходуют лимит. Ограничение количества запросов предотвращает превышение установленного объёма, но фактическую сумму счёта определяет тариф поставщика.

## Проверка сайтов

Сервер выполняет HTTP-проверку с ограничением времени, размера ответа и параллельности. На каждом переходе проверяется публичность IP-адреса; соединение закрепляется за проверенным адресом. Внутренние сети и нестандартные порты запрещены.

Мобильность определяется по viewport, контакты и форма по HTML-признакам, SEO по базовым тегам. Это эвристики: они не подтверждают корректность отображения на телефоне или работоспособность отправки формы. Время ответа включает получение HTML, оно не равно Lighthouse Performance или скорости полной загрузки страницы. JavaScript не выполняется.

Отсутствующая ссылка, непроверенный сайт, ошибка проверки и повторно подтверждённая недоступность различаются. Сетевой сбой или ответ 5xx не доказывает, что компания осталась без сайта.
